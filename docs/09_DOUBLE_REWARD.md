# 임무 성공 시 광고 2배 보상 — v0.1

## 소스 기준
`run_gui.py`: `click_mission_success_confirmation()` 및 `run_one_mission()`의 성공 화면 분기. 이 기능은 별도의 모드가 아니라 **일반 임무 성공 후 확인 버튼보다 먼저 실행되는 선택적 하위 단계**다.

## 진입 조건 (반드시 유지)
1. **같은 프레임**에서 `mission_success_title.png` + `mission_clear.png`가 모두 검출되고 실패 제목이 없어야 성공을 확정한다.
2. `mission.doubleReward.enabled=true` 이고 `mission_double_reward.png`의 재생 아이콘이 성공 화면의 허용 ROI에 있으면 광고 2배 버튼을 우선 클릭한다.
3. 설정이 꺼져 있거나 버튼이 없으면 **추가 대기 없이 일반 `mission_clear` 버튼**으로 성공 처리한다.
4. 실패 화면에서는 절대로 2배 광고 버튼을 누르지 않는다.

## 원본 인식/좌표 (480x1320 기준)
- 재생 아이콘 중심 `(94,1251)`, 탐색 허용 오차 `(55,42)`, 원본 일치율 하한 **0.70** (실기 재검증 후보).
- 클릭할 실제 **2배 버튼 중앙**은 `(146,1251)`를 정규화하여 사용한다. 검출된 작은 아이콘 좌표에 클릭하지 않는다.
- 공용 확인 버튼은 **매번 새 프레임에서** `mission_clear.png`를 탐색한 위치에 클릭한다(실패 결과에서도 고정 좌표 금지).

## 처리 순서
```text
M12 성공 제목+확인 함께 검출
  ├─ 옵션 OFF 또는 2배 아이콘 미검출 → 공용 확인 1회 클릭 → M14
  └─ 2배 아이콘 검출 → M12A
M12A 버튼 중앙 1회 클릭
  → 0.55초 정도 대기 후 화면 갱신
  → 이전 성공 화면과 다른 상태가 실제 관측되었는지 기록
  → 성공 제목 + 공용 확인이 새 프레임에서 다시 함께 보일 때만
     새로운 확인 버튼 좌표를 찾아 클릭
  → 기존 목록/다음 관문 검증 → M14
```
- 원본의 광고 화면/복귀 대기 한도는 **45초**. v0.1에서는 45초 안에 복귀가 증명되지 않으면 추가 터치 없이 `NeedsUserAction`으로 종료한다(자동 복구 금지).
- **광고 전환이 관측되기 전** 기존 성공 화면의 확인을 클릭하면 광고가 취소될 수 있으므로 누르면 안 된다.
- 성공 화면으로 돌아온 것만으로 **광고 시청 완료나 2배 보상 지급이 증명되지는 않는다**. 지급 확인 UI가 없는 경우 로그는 `reward_ad_tapped`, `returned_to_success` 등의 상태만 기록한다.
- 뽑기/거울과 관련 없는 독립 기능이다. 사용자 선택 옵션을 제공하고 기본값은 v2.0.6 동작을 이어받아 ON으로 둔다.

## 코덱스 테스트
`V01-A01` ~ `V01-A06`: 조건별 광고 클릭, 미표시, 설정 OFF, 광고 중 이전 확인 좌표 클릭 금지, 복귀 시 새 확인 탐색, 타임아웃, 실패 화면 금지. 실기 검증은 실제 광고 표시 시나리오를 포함한다.
