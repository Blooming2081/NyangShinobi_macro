## 실제 앱플레이어 테스트 (반드시 별도 수행)
- MuMu / BlueStacks 각각: 해상도 480x1320 기준 장면별 PNG 확보.
- 결과 화면 제목과 공통 확인 버튼 동시 검출 테스트.
- 거울 `image6` 실제 의미와 클리어 화면의 고유 증거 확인.
- 룰렛 버튼 등장/소멸 길이, 특수 비기 Wave/HP 타이밍 실측.
- 프리셋 6~10 번호/스크롤 안정화 실전 검증.
- 네코 뽑기 화면/결과 화면의 3개/2개 ROI가 실제 디스플레이 스케일에서 정확히 동작하는지 검증.
- 2배 광고 전환 및 복귀 시 성공 화면 재탐지, 광고 없이 성공 처리, 보상 미지급 시 표시·중지 동작 검증.
- 버퍼 누수/연속 실행 CPU·메모리·게임 FPS 비교. 목표 수치 실측 전 미확정.

> 패키지의 원본 템플릿 이미지는 **검출 대상**이지 올바른 런타임 장면의 정답 레이블이 아니다. 실제 전투 캡처 fixture가 추가되어야 이미지 인식 회귀 테스트를 통과했다고 말할 수 있다.
