# Task 07 — 네코 닌자 뽑기 및 광고 2배 보상 (v0.1 P1)

## 구현 순서
1. `docs/08_NEKO_NINJA.md`, `docs/09_DOUBLE_REWARD.md`, `data/workflows.v0.1.json`, `data/screen_catalog.v0.1.json`을 먼저 읽는다.
2. `neko_ninja` 별도 실행 모드와 UI 모드 선택/재화 소비 경고/즉시 정지 구현. 예상 화면에만 10회 뽑기 또는 결과 계속하기 1회 입력.
3. 임무 성공 M12의 선택적 M12A 분기 추가. 성공 확인보다 **2배 광고 버튼 우선** 처리하고, 화면 전환 후 성공 확인을 새로 탐색.
4. 원본 ROI/기준/좌표는 참조 발췌·기계 판독용 JSON을 그대로 후보로 사용하고, 실제 앱플레이어에서 검증하기 전 임의로 변경하지 않는다.
5. 테스트 `V01-N01`~`V01-N05`, `V01-A01`~`V01-A06` 작성. 광고/결과 불확실성, 자동 중복 탭 방지, 사용자 중지 후 입력 없음 검증.

## 제약
- 스톨 복구, 워치독, 앱플레이어 재시작, 재화 자동 구매, 광고 강제 건너뛰기, 알 수 없는 UI 고정 좌표 반복 클릭을 구현하지 않는다.
- 3초 기본 주기/터치 완료 0.5초 검증과 상태 확인을 준수한다. 원본 네코 50ms 반복을 그대로 복사하지 않는다.
- `V01-P03` 범위 테스트에서 뽑기·광고는 명시적 모드/성공 상태에서만 실행된다.

## 수용 기준
- 뽑기 모드는 오직 명시적으로 선택했을 때만 동작하고 다른 화면에 터치하지 않는다.
- 광고 2배 버튼이 없다면 기존 정상 성공 처리에 지연을 추가하지 않는다.
- 광고 전환 중 옛 확인 버튼 좌표를 누르지 않는다.
- 실패·불확실한 화면에서 일시 중단 시 추가 입력이 없다.
