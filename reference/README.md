# v2.0.6 발췌 소스 주의 사항

- 이 폴더의 `.py.txt`는 Codex에게 원본의 분기 **순서와 조건**을 전달하기 위해 추출한 읽기 전용 자료다.
- **실행/컴파일 대상 아님**. 클래스 외부에 분리했으므로 Python 코드로 실행할 수 없다.
- 본문에 `recovery`, `restart`, `checkpoint`, `learning`, watchdog 등 v0.1 제외 항목 호출이 남아 있을 수 있다. 그 호출은 **절대로 이식하지 않는다**.
- 재시도 중 '클릭 후 화면 확인'은 게임 진행 검증이므로 유지하되, 장치/게임 복구를 호출하지 않는다.
- 바인딩되지 않은 상수/헬퍼나 문맥은 `data/source_index.v0.1.json`과 문서/원본 ZIP을 통해 확인한다.
