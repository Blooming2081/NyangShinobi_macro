# 이벤트 이미지 보관 폴더

실제 게임에서 획득한 이미지들만 `assets/events/<event_id>/`에 추가한다.
예: `assets/events/example_limited_time_popup/title.png`, `close.png`.

**현재 예시 이벤트는 disabled 상태이며 이미지가 존재하지 않으므로 실행 대상이 아님.**
이 폴더와 예시 JSON은 새로운 이벤트의 파일 배치·계약을 설명하기 위한 것이며 게임 이벤트 화면을 추측한 것이 아니다.

개별 에셋은 해시, 해상도, ROI, 검출 기준, 취득 날짜/앱플레이어를 `data/events/`의 정의 파일과 테스트에 기록한다.
